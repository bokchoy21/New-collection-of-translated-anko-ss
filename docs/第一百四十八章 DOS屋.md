第一百四十八章 DOS屋

完了···
“你到底是什么人，要来干什么”
DOS终于忍受不了这种压抑气氛，张嘴发问
之前也遭遇过各种人类
但不同于之前遇到的人类
面前这个奇怪的人类
穿戴着绣有“鬼”字的黑色头罩和披风
周身散发出恐惧的气息
而且自从来到族群面前就没有说过一句话

这个人类是不能油库里的
因为DOS已经狠清楚地分辨出
他的头罩、披风、上衣、裤子，以及装饰
全都是用各个种族油库里的帽子和发饰缝制的
只有油库里能闻到的死油库里的味道
不断刺激着族群的嗅觉

不安的气氛在族群中蔓延
虽然因为DOS气场的庇护
没有立刻吐馅昏迷
但油库里们还是紧张地躲在DOS身后

“不能油库里的人类就油库里的去死！”
一直拖延下去也不会有结果
即使有着直径4米的巨大体型
也不能对这个恶鬼般的人类放心
DOS在判断之后决定发动魔炮攻击

巨大的光束扫射之后
却没有看到人类的身影
“跑到哪里去了”
DOS四处张望着
全然没有注意到人类已经跃上自己的头顶

掀开DOS巨大的尖顶帽
人类果断地将藏在里面
用来发射魔炮的魔法菇掷向远方

可恶的人类
DOS拼命晃动身体
试图赶走头顶的人类
因为帽子下的头发里
还藏有比香菇更重要的东西
族群中最弱小最可爱的小宝宝
幼油库里们

成功了
DOS看着跳到地面的人类
不由露出笑意
但这份笑意立刻僵在DOS脸上
因为人类已经向DOS摊开手掌
掌心正是那些毫无抵抗能力的幼油库里

挑衅一样
人类把小宝宝们放进上衣口袋
留下一只在手中
然后当着DOS的面捏爆

想要发射魔炮却已经没有香菇
狂怒的DOS飞身跃起压向人类
人类则灵巧地回避着攻击
同时不断从口袋里取出幼油库里
一只只捏爆

别有用心的人类
故意跳向油库里密集的地方躲避
但一心报仇的DOS已经完全听不进
族群的呼喊和求救声

追逐不知持续了多久
DOS已经没有体力驱动巨大的身体
气喘嘘嘘地瘫在地上
无能为力地望着人类
把口袋中剩余的小宝宝全部捏爆
还有地上大片的豆馅和发饰
那是被自己压死的同胞们

随手捡起地上的帽子
擦掉手上和鞋子上的豆沙
人类提着自己的行囊
走进族群居住的山洞中

山洞中很快冒出了烟和火
DOS明白族群的油库里的家和好吃的饭先生没有了
人类另一只手多出了一个捆住的网兜
族群最后的幸存者
几十只躲在洞中没有出来的子油库里们
正在里面拼命挣扎呼喊

“无论怎样！请至少放过孩子们！”
DOS拼命做出恳求
但隔着面罩看不到表情
败者也没有资格提出要求

把网兜丢在一边
人类抓住DOS的上下颚用力撕开
DOS的嘴巴立刻夸张地变大
熟练地拔掉牙齿和舌头
DOS再也不能发射魔炮和说话

从行囊中拿出铁锥
将DOS四角钉在地上
DOS从此再也不能移动
从行囊中拿出小铁铲
钻进DOS体内
像挖土一样挖出内馅
随意泼向四周
很快巨大的身体就被挖出一大块空间

因为看不到体内
所以不知道人类在干什么
但DOS有着比普通油库里更坚韧的外皮
更致密的内馅
这种痛苦还可以忍耐

不知过去了多少时间
人类终于从DOS嘴里跳出来
被挖去大量内馅的DOS
已经完全失去了行动能力
只剩下意识勉强还算清醒

现在的DOS，就像人类搭建的林中小屋
特意保证了内壁的厚度
“小屋”不会随便坍塌
暂且将之命名为DOS屋
抓起装着有子油库里的袋子
一口气全部倒进DOS屋

人类取出铁丝，缝住DOS破裂的大嘴
DOS屋顿时一片黑暗
但很快又再次迎来光明
因为人类用铁铲柄捅穿了DOS的双眼
给DOS屋开了两个天窗

最后用小刀在DOS屋底部开了一个成体油库里大小的洞
装上一扇只能进，不能出的活板门
人类离开了这个地方

重获自由的子油库里们
紧张地观察着新环境
巨大的活动空间
遮风挡雨的厚实“墙壁”
又软又湿润的温暖“地面”
整个“巢穴”还散发出豆馅的香味
试探着咬一口下去
嚼—嚼——好幸福！

死里逃生的子油库里们大声欢呼着
完全忘记了之前的惨状
现在牠们只是在庆幸
自己获得了这个最能油库里的天堂

没有外敌袭击，没有风吹雨打，没有冰冷刺馅
充足的空间可以尽情玩耍
无论怎样翻滚都软软的地面
更重要的是完全不用为食物烦恼
只要张开嘴，就是比杂草和昆虫强百倍的好甜好甜
这一切只能用一个词形容，就是“油库里！”

接下来的日子
子油库里们尽情玩，尽情吃，尽情睡，尽情速鸡立，尽情嗯嗯和嘘嘘
寸步不离DOS屋，虽然牠们也无法打开活板门

DOS从看到人类把孩子放进自己体内，就已经安心了
虽然自己不能动，不能看，不能说话
只要族群还在，DOS的天性就能得到满足
被吃掉内馅虽然会痛，但还可以忍耐
空虚的身体虽然很饿，但子油库里的嘘嘘和嗯嗯还是可以被内馅当做食物消化
以补充失去的营养

子油库里逐渐成长，食量也开始增大
一些油库里已经胖到从可爱的球状体型
变成像蛆虫一样的恶心体型
连动都不愿意动一下
饿了就歪过头咬内馅
吃完直接就地排泄也不担心卫生问题
因为排泄物会被DOS内馅消化掉

油库里们吃掉的DOS馅越来越多
DOS的身体补充速度渐渐跟不上了
DOS也越来越饿

于是在一个夜晚，DOS和油库里都睡过去后
DOS身体的消化本能开始工作
更快地消化体内可以作为食物的东西
一只成体油库里和两只子油库里在睡梦中
不知不觉地被DOS的身体消化
变成新的内馅，被其他油库里吃掉

但其他油库里根本没有发现这件事
因为牠们是凭空消失的，没有任何痕迹
而且这里是油库里天堂，可以让油库里快乐到忘记一切
所以DOS屋的居民开始渐渐变少

但DOS毕竟还活着
依然能够像平时一样
出于本能地向四周发散DOS气场

于是时常有被吸引而来的野生油库里
虽然起初牠们对这个奇怪的DOS感到不安
但DOS体内传来很能油库里的声音和香味
使得这些访客毫不犹豫地钻进活板门
成为DOS屋的成员
享受着，同时也维持着这个油库里永远的“天堂”。
